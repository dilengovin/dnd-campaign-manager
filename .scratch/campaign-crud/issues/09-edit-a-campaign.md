# 09: Edit a Campaign

**What to build:** A User changes a Campaign they have already recorded —
correcting a mistake, adding a Player who joined, and above all writing up the
session they just played. Logging into Notes is the thing a User will do most
often once the app holds real games.

The form arrives filled in with the Campaign's current values, so a User only
changes what they mean to change. It offers the same fields and the same
name-is-required rule as recording, and Players are added and removed the same way.

An edit can be abandoned without saving. Opening the form to look at something must
not be the same as changing it.

**Blocked by:** 08.

**Status:** ready-for-agent

- [ ] A Campaign can be opened for editing from its detail page
- [ ] The form arrives populated with the Campaign's current values
- [ ] Changes are saved and immediately visible
- [ ] Players can be added and removed while editing
- [ ] Notes can be updated — the session-logging path works end to end
- [ ] The name is still required; nothing else is
- [ ] Abandoning the edit leaves the Campaign untouched
- [ ] Edits survive a reload
